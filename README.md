# העוזר שלי

עוזר אישי לטלפון: משימות עם תיבות סימון, תזכורות, התראות, רשימות ותתי-משימות. זו אפליקציית ווב (PWA): פותחים אותה בדפדפן של הטלפון, מוסיפים למסך הבית, והיא עובדת כמו אפליקציה רגילה, גם בלי אינטרנט.

## מה יש בה

- **היום**: ברכה, תאריך לועזי ועברי, טבעת התקדמות, משימות באיחור ומשימות להיום.
- **בקרוב**: משימות לשבוע הקרוב לפי ימים, מאוחר יותר, וללא תאריך.
- **חשוב**: כל מה שסומן בכוכב (מודגש במרקר צהוב בכל הרשימות).
- **רשימות**: אישי, עבודה, בית, קניות, ואפשר להוסיף רשימות עם צבע.
- **הוספה במשפט אחד**: כותבים "להתקשר לאמא מחר ב-18:00 !" והעוזר מזהה תאריך, שעה, תזכורת וחשיבות.
- **משימות חוזרות**: כל יום, ימי חול (א׳–ה׳), כל שבוע, חודש או שנה. סימון כבוצע מעביר אותה למועד הבא.
- **תתי-משימות** עם תיבות סימון, למשל רשימת קניות.
- **תזכורות**: בזמן המשימה, 10 דקות, חצי שעה, שעה או יום לפני. נודניק של 10 דקות.
- **הוספה ליומן** (קובץ ‎.ics או Google Calendar).
- ביטול פעולה, חיפוש, מצב כהה, גיבוי ושחזור לקובץ, מספר משימות באיחור על האייקון.
- **תזכורות לטלפון גם כשהאפליקציה סגורה**, דרך שרת קטן וחינמי (ראו בהמשך).

### מה אפשר לכתוב בהוספה מהירה

| כותבים | מה מזוהה |
| --- | --- |
| `היום`, `מחר`, `מחרתיים`, `הערב` | תאריך |
| `ביום חמישי`, `בשבת`, `שבוע הבא`, `ב-12/3` | תאריך |
| `ב-18:00`, `בשעה 9`, `ב-8 בערב`, `בבוקר` | שעה (ותזכורת אוטומטית) |

| `!` או `דחוף` | חשוב |
| `#עבודה` | רשימה (רשימה חדשה נוצרת אם אין כזו) |
| `תזכיר לי ...` | תזכורת |

## איך תזכורות עובדות

תזכורות נשלחות לטלפון כהתראה רגילה, **גם כשהעוזר סגור**, דרך שרת קטן (תיקיית `server/`) שרץ בחינם ב-Cloudflare:

1. כל משימה עם תזכורת נשלחת לשרת (שם המשימה והשעה), כולל השבועיים הקרובים של משימות חוזרות.
2. השרת מעיר את עצמו בדיוק בזמן התזכורת ושולח התראת Web Push דרך Apple או Google.
3. לחיצה על ההתראה פותחת את העוזר על כרטיס התזכורת, עם "בוצע" ו"עוד 10 דקות".

- **iPhone (iOS 16.4 ומעלה)**: התראות עובדות רק אחרי "הוספה למסך הבית" מתוך Safari, ופתיחת העוזר מהאייקון.
- **Android (Chrome)**: עובד גם בדפדפן וגם אחרי התקנה, כולל כפתורי "בוצע" ו"עוד 10 דקות" על ההתראה עצמה.

בלי שרת (למשל בפיתוח מקומי), תזכורות מגיעות רק כשהעוזר פתוח או ברקע, ואפשר להוסיף משימה ליומן של הטלפון ממסך העריכה.

המשימות עצמן נשמרות במכשיר (localStorage). לשרת נשלחים רק התזכורות הקרובות. כדי להעביר משימות לטלפון אחר: הגדרות ← שמירת גיבוי, ובטלפון החדש ← שחזור מגיבוי.

## הגדרה חד-פעמית

### 1. GitHub Pages (האתר)

ב-GitHub: **Settings ← Pages ← Source: GitHub Actions**. הכתובת תהיה `https://dolevifr.github.io/claude-mobile-game/`.

### 2. שרת התזכורות ב-Cloudflare (חינם)

1. נרשמים ב-[dash.cloudflare.com](https://dash.cloudflare.com/sign-up) ונכנסים פעם אחת ל-**Workers & Pages**, כדי שתיווצר כתובת `workers.dev` לחשבון.
2. יוצרים מפתח: **My Profile ← API Tokens ← Create Token**, בוחרים בתבנית **Edit Cloudflare Workers**, ממשיכים ויוצרים. מעתיקים את המפתח.
3. מעתיקים את ה-**Account ID** (מופיע בעמוד Workers & Pages, בצד).
4. ב-GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret**, ומוסיפים שניים:
   - `CLOUDFLARE_API_TOKEN` עם המפתח
   - `CLOUDFLARE_ACCOUNT_ID` עם ה-Account ID
5. ב-GitHub: **Actions ← Deploy ← Run workflow**. השרת עולה, והכתובת שלו נכנסת לאפליקציה אוטומטית.

### 3. בטלפון

1. פותחים את כתובת האתר ב-Safari, לוחצים על כפתור השיתוף ← **הוספה למסך הבית**.
2. פותחים את העוזר מהאייקון ולוחצים על **הפעלת התראות** (בבאנר במסך "היום", או בהגדרות). מאשרים.
3. בהגדרות לוחצים על **התראת ניסיון**. אם היא הגיעה, הכל מוכן.

## פרסום

ה-workflow שב-`.github/workflows/pages.yml` מריץ את הבדיקות, מעלה את שרת התזכורות ל-Cloudflare (אם הוגדרו המפתחות), ומפרסם את האתר בכל push ל-`main`. אפשר גם לקבוע כתובת שרת אחרת דרך משתנה המאגר `PUSH_SERVER_URL`.

אחרי שינוי בקבצי האפליקציה כדאי לעדכן את `VERSION` ב-`sw.js`, כדי שטלפונים שכבר התקינו יקבלו את הגרסה החדשה.

## פיתוח

אין שלב build: HTML, CSS ו-JavaScript (ES modules) רגילים.

```bash
npm start   # שרת מקומי בכתובת http://localhost:8080
npm test    # בדיקות: זיהוי משפטים, תאריכים, חזרות, ייצוא ליומן, הצפנת Web Push

cd server && npm install && npx wrangler dev   # שרת התזכורות מקומית, בכתובת http://localhost:8787
```

כדי שהאפליקציה המקומית תשתמש בשרת המקומי, כותבים את כתובתו ב-`js/config.js`.

| קובץ | תפקיד |
| --- | --- |
| `index.html` | מבנה המסך |
| `css/app.css` | עיצוב, כולל מצב כהה |
| `js/app.js` | מסכים, טפסים ואירועים |
| `js/store.js` | הנתונים, שמירה ושליפות |
| `js/parse.js` | זיהוי תאריך, שעה וחזרה מתוך משפט |
| `js/dates.js` | תאריכים, תאריך עברי, חזרות |
| `js/reminders.js` | תזמון תזכורות בתוך האפליקציה, התראות, ייצוא ליומן |
| `js/push.js` | הרשמה להתראות וסנכרון התזכורות עם השרת |
| `js/config.js` | כתובת שרת התזכורות (נכתבת בזמן הפרסום) |
| `sw.js` | עבודה בלי אינטרנט, הצגת התראות מהשרת וכפתורי ההתראה |
| `server/src/index.js` | שרת התזכורות: שמירת התזכורות לכל טלפון והשליחה בזמן |
| `server/src/webpush.js` | חתימת VAPID והצפנת Web Push, בלי ספריות חיצוניות |
